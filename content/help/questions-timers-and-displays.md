## Collect group questions

Participants can ask a question from their session page and vote for questions from the same room. Hosts see them in **Group questions** on the dashboard.

Mark a question answered when it has been addressed. Use **Show answered** when you need to revisit completed questions.

## Screen participant questions

Turn on **Screen group questions** in **Room controls** before class if questions need approval. New questions remain hidden from other participants until a host selects **Show**.

Hosts can hide a visible question later. Screening group questions is separate from **Screen submissions**.

## Start or clear the timer

Enter the duration under **Timer** and select **Start**. The countdown is shown on the host dashboard and participant pages. Use the adjustment buttons to change the time during an activity, or select **Clear** to remove the active timer.

The general session timer is separate from a poll’s voting timer.

## Choose a projector display

- **QR popout** helps participants join.
- **Pop out submissions** presents the moderated response stream.
- A response-chart **Pop out** presents the current chart and filters.
- The poll results popout presents voting progress and results.

Keep the main dashboard on the host’s screen so moderation controls and private images are not accidentally projected.

## Work with another host

Hosts in the same session share its live prompt and control state. They also share response filters, card order, and expanded-card choices used by the submissions view.

Agree who will change prompts and display controls during class. If another host changes the prompt, Ed.ie reports that change and refreshes the dashboard.

## Troubleshoot an out-of-date projector

1. Confirm the popout belongs to the current session.
2. Check the prompt and time filters in **Room controls**.
3. Refresh the popout window if it lost its live connection.
4. Check whether another host has changed the shared display settings.
