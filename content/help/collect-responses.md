## Choose the available inputs

Open **Room controls** and find **Participant inputs**. You can independently enable:

- **Text responses**;
- **GIF responses**;
- **Drawings**;
- **Image uploads**; and
- **Image embeds** in written Markdown.

Changes appear on participant screens. Turning an input off removes that input for new work but does not delete content already submitted.

## Collect text and drawings

Text responses can contain up to 2,000 characters. Participants can use the formatting controls for simple Markdown.

The drawing pad collects pen strokes rather than a conventional uploaded image. A drawing can be submitted on its own or alongside text when both inputs are available.

## Collect GIFs and images

GIF search is available only when it has been configured for this Ed.ie installation. Searches and selected media use GIPHY; participants should not put names, student IDs, or sensitive details into search terms.

Private image uploads are also configuration-dependent. When available, Ed.ie converts the image in the participant’s browser to remove metadata before upload. Uploaded images are visible to authenticated hosts, not to other participants.

**Image embeds** controls remote images included in written Markdown. This is separate from a private image upload.

## If the session closes while someone is writing

The participant can still read the prompt, but a new response cannot be submitted while **Accepting responses** is off. Reopen access if you want them to finish and submit. Their unsent draft may still be visible in that browser, but participants should not rely on it being retained.

## Troubleshoot missing or failed responses

1. Confirm **Accepting responses** is on.
2. Confirm the required input is enabled under **Participant inputs**.
3. Check whether **Screen submissions** is holding the response as hidden.
4. Remove prompt and time filters under **Display & filters**.
5. Use **Refresh responses**.

For failed images, try a smaller common image format and confirm **Image uploads** is enabled. If the image control is absent for everyone, uploads may not be configured on this deployment.
