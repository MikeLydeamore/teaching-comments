## Share a QR code

1. Open the intended session dashboard.
2. Select **QR popout** in the header.
3. Display the new window on the projector.

The QR link contains both the hosted-space and session codes. Participants can scan it with their phone camera and do not need to sign in.

## Share codes instead

Direct participants to `/join` and give them the hosted-space code and session code shown for the activity. Codes ignore capitalisation and unnecessary surrounding spaces.

This option is useful when someone cannot scan the projected QR code or is joining from the device on which they are viewing it.

## Open and close participant access

Use **Accepting responses** in the dashboard header:

- on: participants can submit, ask or vote for group questions, and take part in a live poll;
- off: participants can still read the prompt, but cannot start new activity.

Closing access does not hide the session from hosts or delete existing work. You can turn it on again later.

## Let participants use a name or stay anonymous

The participant name is optional. A blank name is stored and displayed as Anonymous. Ask participants not to enter student IDs or sensitive information.

## Troubleshoot a participant who cannot join

Check these in order:

1. Confirm they used the hosted-space code and session code from the same dashboard.
2. Confirm **Accepting responses** is on.
3. Ask them to return to `/join` and enter the codes again, or rescan a newly opened QR popout.
4. Check whether the participant can load Ed.ie on their network using another browser.

If one old QR code is affected, stop displaying it and open **QR popout** again from the current session.
