## Export responses to CSV

Open **Room controls** and select **Export CSV**. The export contains the session’s response data for use in a spreadsheet.

Export includes hidden and archived responses, not only the cards in the current filtered view. Treat the file as teaching data and store or delete it according to your institution’s requirements.

Poll results have their own **Download CSV** action in the poll panel.

## Clear and archive the live room

Select **Clear / archive room** under **Data actions**. Confirm the action after checking that you are in the intended session.

This removes the current responses and group questions from the live room while retaining them in the archive and session CSV export. It does not delete the hosted space or session, and it does not change the current prompt.

Use this when you want a clean live stream for another activity but need to retain the earlier dataset.

## Undo a recent archive

Immediately after archiving, select **Undo archive** to restore that archived batch to the live room. The shortcut is tied to the most recent archive action shown on that dashboard.

If you leave or reload the page, do not assume the shortcut will remain available. Export before clearing when retaining a local copy is important.

## Permanently delete activity

Ed.ie currently has no self-service control for permanently deleting a session or its archived activity. **Clear / archive room** is not deletion.

If permanent deletion is required under your class or institution’s retention policy, contact the administrator or data owner responsible for your Ed.ie deployment. Identify the hosted space and session code, but do not send participant content through an insecure channel.

## Understand hidden, filtered, closed, and archived work

| State | Still stored | Visible in the normal stream | Accepts new work |
| --- | --- | --- | --- |
| Hidden response | Yes | No | Unchanged |
| Filtered response | Yes | Only when it matches the view | Unchanged |
| Closed session | Yes | Yes to hosts | No |
| Archived activity | Yes | No | The session can collect new activity |
