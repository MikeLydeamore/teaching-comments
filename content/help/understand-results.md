## Read the session summary

**Session totals** separates all active responses into visible and hidden counts. A hidden response is still stored and available to hosts; it is not included in the normal projected stream.

**Common words** counts frequently used words across active written responses. Treat it as a quick orientation rather than a measure of understanding: repeated wording, spelling, and short responses can strongly affect the result.

## Visualise the current response view

Select **Visualise results** above the live writing stream. The chart uses typed responses from the current prompt and time filters in **Room controls**.

Choose:

- **Column** to compare distinct answers;
- **Pie** to see the relative share of distinct answers; or
- **Word cloud** to emphasise frequently used words.

Column and pie charts work best for short, deliberately constrained answers. A word cloud is more suitable for open text, but it does not preserve sentence meaning.

## Read the response-time plot

The response-time plot shows when responses arrived relative to the start of the selected prompt. Use it to see the pace of participation, not to judge an individual participant.

Changing the prompt filter changes the reference point used by the plot.

## Present or download results

Select **Pop out** from the response chart for a projector-friendly result view. The popout follows the current shared response filters.

Use **Export CSV** in **Room controls** when you need the underlying responses rather than a visual summary. Poll results use the separate **Download CSV** action inside the poll panel.

## Avoid over-interpreting a chart

Ed.ie summaries are designed for formative classroom discussion. Before drawing a conclusion, check how many people responded, whether screening or filters are active, and whether differently worded answers express the same idea.
