## Join a session

Scan the QR code shown by your host, or open `/join` and enter the hosted-space code and session code they provide. You do not need an Ed.ie account.

If the QR code opens an old activity, return to `/join` and type the current codes.

## Choose whether to provide a name

The name field is optional. Leave it blank to submit as Anonymous. Do not enter a student ID or sensitive personal information in your name, response, drawing, question, or GIF search.

## Send a response

Use whichever inputs your host has enabled: text, a drawing, a GIF, or an image. You may be able to combine text with another response type. Review the content, then use the submission button.

Available inputs can change during the activity. If an input disappears, the host has disabled it; choose one of the remaining options or wait for instructions.

## Answer a poll

A live poll appears over the session page. Choose one answer in a single-choice poll or all relevant answers in a multiple-choice poll, then submit before voting ends.

The host controls when results and any correct solution are shown.

## Ask or vote for a group question

Use **Group questions** to ask something for the room. You can vote for an existing question instead of submitting the same question again.

If screening is enabled, a new question may be visible only to the hosts until they approve it. Questions marked answered can be moved out of the active list.

## Understand who can see your work

Authenticated teaching staff for the hosted space can see submissions and group questions. Other participants can see group questions that the host makes visible. A host may choose to discuss or project responses during class.

Private uploaded images are available to authenticated teaching staff and are not shown to other participants. See the [privacy notice](/privacy) for more detail.

## When the session is closed

You can still read the prompt, but you cannot send new responses, questions, votes, or poll answers. Keep the page open if your host says they will reopen it; otherwise ask the host for the correct current session.
