## My students cannot join

The usual cause is a mismatched code or closed participant access.

1. Confirm the hosted-space code and session code from the same dashboard.
2. Turn on **Accepting responses**.
3. Ask the participant to return to `/join` or scan a newly opened **QR popout**.

If only one device is affected, try another browser or network on that device.

## The QR code opens the wrong session

Close the projected QR window and select **QR popout** from the intended session dashboard. Do not reuse a QR window left open from an earlier activity.

## Students can submit, but I cannot see responses

The responses are usually screened, hidden by a filter, or arriving in a different session.

1. Open **Room controls** and choose **All prompts** and **All time**.
2. Check whether **Screen submissions** is on and review hidden cards.
3. Select **Refresh responses**.
4. Compare the participant’s two codes with the host dashboard.

## An image will not upload

Confirm **Image uploads** is enabled under **Participant inputs**. Try a PNG, JPEG, WebP, HEIC, or HEIF file no larger than 10 MiB. If the image option is missing for everyone, private uploads may not be configured on this deployment.

## My prompt has not changed

Select **Show** after editing and look for the saved status. A question loaded from the bank is only a draft until it is shown. Another host in the same session may also have changed the prompt.

## I cannot start a poll

Turn on **Accepting responses**, end any current live poll, and check that the poll has two to eight non-empty answers. A single-choice poll must have exactly one correct answer.

## I do not see any hosted spaces

Open **Invitations** from the account menu and check that you signed in with the invited account. See [Get access to a hosted space](/help/access-hosted-spaces#if-you-do-not-see-any-hosted-spaces).

## I cannot invite another teacher

Only owners can manage access. Use the colleague’s exact Ed.ie username or sign-in email. If you are an editor, ask an existing owner to send the invitation.

## The projector is showing old responses

Confirm that the popout belongs to the current session. Remove prompt and time filters, refresh the popout if its live connection was interrupted, and check whether another host changed the shared display settings.
