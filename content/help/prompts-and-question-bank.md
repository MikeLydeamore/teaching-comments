## Show or change a prompt

1. Write or edit the text in **Prompt**.
2. Select **Show**.

Participants see the saved version. Your draft remains private until you select **Show**, which lets you prepare the next question without changing their screens.

Showing a new prompt does not delete earlier responses. Ed.ie begins a new prompt-history period so responses can be viewed by prompt later.

## Save a useful question

After writing a prompt, select **Add to bank**. Give it a clear title that will make sense when you return to it later.

To reuse it, choose it from **Question bank**, make any changes you need, and select **Show**. Loading a saved question does not show it to participants automatically.

Deleting a saved question removes it from the bank; it does not remove a prompt that was already shown or the responses collected for it.

## View responses from an earlier prompt

1. Open **Room controls**.
2. Under **Display & filters**, open **Prompt**.
3. Choose the earlier prompt, or select **All prompts** to remove the filter.

The filter changes the current host and popout display. It does not delete responses.

## Decide whether to change prompt or session

Use another prompt for the next question in the same continuous activity. Create another session when you need a separate dataset or a clearly separate participant destination.

## Troubleshoot a prompt that has not changed

- Confirm you selected **Show** after editing.
- Look for the “Prompt saved” status beneath the editor.
- If another host is working in the same session, check whether they have just shown a different prompt.
- Ask the participant to keep the page open briefly; prompt changes arrive as live updates.
